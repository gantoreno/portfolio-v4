# gantoreno.com

My website, built with Astro and deployed on Vercel. Visit [gantoreno.com](https://gantoreno.com).

![gantoreno.com](public/assets/img/og.png)

Use Node.js 24 and Bun 1.3.10.

```sh
bun install
bun run dev
```

Run `bun run build` to build the site, `bun run test` to check the production output after building, and `bun run create:article` to scaffold a blog post.
